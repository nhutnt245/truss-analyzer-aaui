# Styled example: selection-cards (kind B: one thing to click)

Generated by the kit's recipe build: the React form is `src/recipes/styled/SelectionCards.tsx` as it is, the HTML is what the real AtomicAUI 7.0.9 parts rendered from it. Do not edit this page (AUI-13).
Use for: Pick one of a few, all visible, as cards, with one line of words or a title and text; the picked one stands out.
In our apps: A grey outlined card; picked, a 2 px primary outline with the same fill, text and height; all ten apps have it.
Same job: copy the whole block of your stack, change the texts and the data, keep `data-aui-styled="selection-cards"`. Another job: keep this page open as your pattern. In React, copy the file into your screen folder; do not import it from `src/recipes/styled/` (AUI-09).

## React: one file in your screens folder
```tsx
import { Type, View } from '@/vendor/atomic-aui';
import { SELECTED_CARD_AUI } from '@/recipes/shared/aui';

// STYLED PIECE: selection cards. AtomicAUI 7.0.9 has `CardGroup`, but its picked card does not match our apps (GAPS.md). Kind B, one clickable surface per card.
// root : arranger        (a named group; cards wrap; gap 4)
//   card: selection card (the kit's picked look, SELECTED_CARD_AUI)
//     text: body text    (p3; with a `description`: the title in semi-bold, then the description, both p3)
// States: picked, by `selected` and `aui.states`. Sizes: both states are the same height. Icons: none.

const CHOICE_GROUP_AUI = { paint: 'text', profile: 'no-padding', sx: { display: 'flex', flexWrap: 'wrap', gap: '4', width: 'fill' } } as const;
// The picked look is the kit's. After the spread comes layout only: `sx` with no colour and no border.
const CHOICE_AUI = {
  ...SELECTED_CARD_AUI,
  sx: { display: 'flex', flex: 'fill', flexDirection: 'column', alignItems: 'center', justifyContent: 'center', gap: '4', minHeight: '28', minWidth: '96', paddingInlineStart: '4', paddingInlineEnd: '4' },
} as const;
const CHOICE_TEXT_AUI = { sx: { whiteSpace: 'normal', textAlign: 'center' } } as const;

export interface SelectionOption {
  value: string;
  /** One line of words, or the title of a card that also has a description. */
  label: string;
  /** The text under the title. Leave it out for a card of one line. */
  description?: string;
}

/** Pick one of a few, all visible, as cards. Picking a card moves nothing. */
export function SelectionCards({ label, options, value, onChange }: { label: string; options: readonly SelectionOption[]; value: string; onChange: (value: string) => void }) {
  return (
    <View role="group" aria-label={label} data-aui-styled="selection-cards" aui={CHOICE_GROUP_AUI}>
      {options.map((option) => (
        <View key={option.value} as="button" interactive selected={value === option.value} aui={CHOICE_AUI} onClick={() => onChange(option.value)}>
          <Type as="span" role="p3" weight={option.description ? 'semi-bold' : undefined} aui={CHOICE_TEXT_AUI}>{option.label}</Type>
          {option.description ? (
            <>
              {/* A space between the two lines: the card's accessible name reads "Title Description", and a screen reader does not run them together. */}
              {' '}
              <Type as="span" role="p3" aui={CHOICE_TEXT_AUI}>{option.description}</Type>
            </>
          ) : null}
        </View>
      ))}
    </View>
  );
}
```

## Any other stack: the same piece as class lists
You add: Copy the group of your cards: the first group is a card of one line, the second a card of a title and text (a `description`: two spans in the card, a space between them in the markup so the name reads "Title Description"). Copy the script under the class lists, once on the page: the clicked card takes the picked class list and aria-pressed="true", every other card the plain list and "false". In the markup, pick the card the source picks, or none. Keyboard, focus ring, hover and pressed come from the native button and the stylesheet.
Change the texts, names and ids only. A class list is one whole string: never shorten, mix or extend it.

The script of this piece (once on the page; it is the whole behaviour):
```html
<script>
  // Selection cards: the clicked card takes the picked class list and aria-pressed="true", every other card the plain list and "false".
  document.addEventListener('click', (event) => {
    const card = event.target.closest('[data-aui-styled="selection-cards"] > button');
    if (!card || card.getAttribute('aria-pressed') === 'true') return;
    for (const other of card.parentElement.children) {
      other.className = 'aui-view aui-frame aui-scale-default-sm aui-typography-typescale-default aui-shape-soft aui-color-tonal-surface aui-frame--inset aui-elevation-0 aui-border-color-outlined aui-padding-inline-start-4 aui-padding-inline-end-4 aui-gap-4 aui-min-width-96 aui-min-height-28 aui-display-flex aui-flex-direction-column aui-align-items-center aui-justify-content-center aui-flex-fill aui-stateful aui-focus-color-info aui-focus-width-2';
      other.setAttribute('aria-pressed', 'false');
    }
    card.className = 'aui-view aui-frame aui-scale-default-sm aui-typography-typescale-default aui-shape-soft aui-color-tonal-primary aui-frame--inset aui-elevation-0 aui-bg-surface aui-fg-on-surface aui-border-block-start-width-2 aui-border-block-end-width-2 aui-border-inline-start-width-2 aui-border-inline-end-width-2 aui-padding-inline-start-4 aui-padding-inline-end-4 aui-gap-4 aui-min-width-96 aui-min-height-28 aui-display-flex aui-flex-direction-column aui-align-items-center aui-justify-content-center aui-flex-fill aui-stateful aui-focus-color-info aui-focus-width-2';
    card.setAttribute('aria-pressed', 'true');
  });
</script>
```
