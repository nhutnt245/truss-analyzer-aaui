# Notices

## Working principles
The four working principles (think before coding, simplicity first, surgical changes, goal-driven execution) are adapted from "Karpathy-Inspired Claude Code Guidelines" (https://github.com/multica-ai/andrej-karpathy-skills, formerly `forrestchang/andrej-karpathy-skills`), which derives them from Andrej Karpathy's public observations on how language models go wrong when they write code. Its README states the licence as MIT. The headings are kept; the wording here is the kit's own and maps each principle to a kit rule.
