# Styled example: label-value-rows (kind A: it only shows things)

Generated by the kit's recipe build: the React form is `src/recipes/styled/LabelValueRows.tsx` as it is, the HTML is what the real AtomicAUI 7.0.9 parts rendered from it. Do not edit this page (AUI-13).
Use for: The facts of one thing, one row per fact: a label and its value.
In our apps: A label column 160 wide, gap 12, block padding 8, a 1 px divider under every row but the last. The 160 is the chip column of the About dialogs (hs AboutDialog.tsx:130-135), not a label column; no app has label rows. The overview recipe shows facts as "Label: value" lines instead.
Same job: copy the whole block of your stack, change the texts and the data, keep `data-aui-styled="label-value-rows"`. Another job: keep this page open as your pattern. In React, copy the file into your screen folder; do not import it from `src/recipes/styled/` (AUI-09).

## React: one file in your screens folder
```tsx
import { Type, View } from '@/vendor/atomic-aui';

// STYLED PIECE: label and value rows. AtomicAUI 7.0.9 has no part for the facts of one thing (GAPS.md). Kind A, display only.
// root : arranger          (a named group, a column)
//   row  : arranger        (gap 12, block padding 8, a divider under every row but the last)
//     label: label         (l4 semi-bold) in a label column of 160
//     value: body text     (p3); it takes the free width, so a long value wraps in its column
// States: none. Sizes: the label column is 160 wide. Icons: none.
// The 160 is the chip column of the apps' About dialogs (hs AboutDialog.tsx:130-135), not a label column: no app puts facts in label rows. The released ADCCP and the ADC prototype write a fact as one line, "Label: value" (adccp CalculationSummary.tsx:968-982). The overview recipe does that.

const ROWS_AUI = { paint: 'text', profile: 'no-padding', sx: { display: 'flex', flexDirection: 'column' } } as const;
const ROW_SX = { display: 'flex', flexDirection: 'row', alignItems: 'start', gap: '12', paddingBlockStart: '8', paddingBlockEnd: '8', borderColor: 'outlined' } as const;
// A look that follows data is a named look per value: the last row is its own constant (AUI-04).
const ROW_AUI = { paint: 'text', profile: 'no-padding', sx: { ...ROW_SX, borderBlockEndWidth: '1' } } as const;
const LAST_ROW_AUI = { paint: 'text', profile: 'no-padding', sx: { ...ROW_SX, borderBlockEndWidth: '0' } } as const;
const ROW_LABEL_AUI = { paint: 'text', profile: 'no-padding', sx: { width: '160', flex: 'none' } } as const;
const ROW_VALUE_AUI = { sx: { flex: 'fill', minWidth: '0' } } as const;

export interface LabelValue {
  label: string;
  value: string;
}

/** The facts of one thing, one row per fact. */
export function LabelValueRows({ label, items }: { label: string; items: readonly LabelValue[] }) {
  return (
    <View role="group" aria-label={label} data-aui-styled="label-value-rows" aui={ROWS_AUI}>
      {items.map((item, index) => (
        <View key={index} aui={index === items.length - 1 ? LAST_ROW_AUI : ROW_AUI}>
          <View aui={ROW_LABEL_AUI}>
            <Type as="span" role="l4" weight="semi-bold">{item.label}</Type>
          </View>
          <Type as="div" role="p3" aui={ROW_VALUE_AUI}>{item.value}</Type>
        </View>
      ))}
    </View>
  );
}
```
