## AtomicAUI
This project uses the AtomicAUI design system (skills 7.0.9-kit.0.4.2). Before any work on screens, read `.agents/skills/atomicaui/SKILL.md` and follow it.
A one-line request about a screen, button or dialog ("Ask for confirmation before Delete."), or a prompt that points at a screenshot or at `specs/`, is a build task for this app: open `.agents/skills/atomicaui/SKILL.md` and every file in `specs/` with a tool before you answer.
A piece AtomicAUI has no part for (cards to pick, rows of facts): read `.agents/skills/aui-style-anything/SKILL.md` before you style it.
